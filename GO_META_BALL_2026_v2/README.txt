GO META BALL 2026
===================

현재 포함된 기능
- 현대적인 반응형 UI
- 온라인 로비 UI: 방 생성 / 6자리 코드 참가
- EPL 20개 팀 선택 화면
- 일부 주요 팀의 실제 선수단 예시 데이터 + 나머지 팀용 기본 포지션 데이터
- 공격 20 / 수비 20 / 특수 10 전술
- 전술 선택 및 경기 중 빠른 전술 변경
- 실시간 텍스트 해설
- 경기 시뮬레이션 / 득점 / 경기 종료
- 업로드된 OST를 assets/ost.mp3로 통합
- 화면 전환 때 BGM이 유지되는 SPA 구조

실행
1. 폴더를 VS Code로 엽니다.
2. index.html을 브라우저에서 실행합니다.
3. 브라우저 정책상 자동 음악 재생이 차단될 수 있으므로 첫 화면에서 한 번 클릭하면 OST가 재생됩니다.

주의
현재 방 코드는 프론트엔드 데모입니다. 실제 친구와 서로 다른 PC에서 접속하는 온라인 멀티플레이를 완성하려면 WebSocket/서버 또는 Firebase 등의 백엔드 연결이 다음 단계로 필요합니다.
